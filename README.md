# Appaji — portfolio

A responsive, dependency-free portfolio site with a pale green and deep blue palette, GitHub-inspired typography and repository cards, pointer-reactive illustration, and a scroll-scrubbed motion section.

## Featured projects

- [HireBridge](https://github.com/appajicse2004-gif/hirebridge) — resume hosting and employer messaging built with React, Vite, and Firebase.
- [Cognictic](https://github.com/appajicse2004-gif/cognictic) — AI-assisted tender and bidder evaluation prototype with document parsing and audit logging.
- [Automated API Testing Framework](https://github.com/appajicse2004-gif/Automated-API-testing-framework-) — a Flask app for test suites, generation, validation, regression checks, and reports.

## Preview locally

Open `index.html` in a browser, or run a local server from this folder:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

Create a public repository named `appajicse2004-gif.github.io`, add these files at its root, and enable Pages from **Settings → Pages → Deploy from a branch → main → /(root)**. GitHub Pages is free for public repositories. The site will be available at `https://appajicse2004-gif.github.io` after the first deployment finishes.
